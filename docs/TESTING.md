# Testing

Every kind of test this repo has, what it covers, and how to run it. `tools/check.sh` runs
all of them in CI's order; `tools/check.sh --fast` skips the builds and browsers.

| Kind | What it covers | Run |
|---|---|---|
| **Unit** (vitest) | The design model (`packages/api/test/design.test.ts`): look picking and fallbacks, template variables and plurals, highlight runs, the branding rule, every validation message (worded like the engine's), media remapping. The built-in catalogue (`packages/designs/test`): every built-in passes the engine's checks; the library's size (12+ themes with five scenes, 30+ alerts, 25+ widget designs by kind, 3+ rotators and timers), about a quarter Pro, a matching alert per theme, structural variety (silhouettes, patterns, frame variants, text effects, 15+ fonts), a tiny Spark in every scene placed around the screen, no mark on duplicates, nothing opaque over a camera, a clear middle in game, and budgets (layers, loops, CSS, catalogue size). Dashboard logic (`apps/dashboard/src/lib/*.test.ts`): undo history, the asset-pack classifier and pairing. Everything older: protocol parsers, TS ports of core logic, overlay runtime. | `pnpm -r test` |
| **Integration** (vitest) | The demo engine's design routes against the real client: every error status (400, 404, 409 `built_in` / `in_use` / `branding`, 413, 415 `bad_design_file` / `unsafe_design_file` / `damaged_design_file` / `unsupported_type`, 422 `design_too_new` / `invalid_design`), `.ferrodesign` export then import, hostile design files, Use for themes, scenes and widgets, designer test alerts with an amount. | `pnpm --filter @ferrocast/api test` |
| **Contract** | The demo engine's shapes against a running engine (`/designs` and `/designs/active-alert` included). Skipped without an engine. | `FERROCAST_ENGINE=http://127.0.0.1:47820 FERROCAST_PAIR=<code> pnpm --filter @ferrocast/api test contract` |
| **Overlay render** (vitest + happy-dom) | `apps/overlays/test/designs.test.ts`: every built-in alert design for every event (frame, layout, title, highlights, where the mark sits), every theme scene (each layer, the mark, live widgets, styled variants), every widget design, unbranded copies (no mark anywhere), hostile viewer names, reduced motion (fades only, no letter animation), finite loops (R-38), exit timing and acks, broken designs falling back to the classic look without the mark, custom CSS that tries to load files; library layers (rotator lines as text, countdown and its done line, silhouettes, patterns, frame variants, text effects, bad values ignored, particles capped, no drift in low motion, per-letter entrances); every scene design and its unbranded copy; every alert in low motion. `apps/overlays/test/fonts.test.ts`: every font a built-in names ships with the app. | `pnpm --filter @ferrocast/overlays test` |
| **E2E** (Playwright, built app, demo mode) | Dashboard `e2e/designs.spec.ts`: gallery dropdown filters, search, tabs, Preview as, Use (alert, theme, widget), Duplicate & customise removes branding, both designer views over the same draft and the remembered view, undo and redo (keys and buttons), timeline sliders, variations, the leave guard, export then import, bad files, the asset-pack importer, layout editor layers (add, hide, lock, undo, align) and the kept mark on built-in overlays. `e2e/designs-mobile.spec.ts`: 375 px in dark and light. Overlays `e2e/designs.spec.ts`: designs in a real browser (Web Animations, reduced motion, scenes). | `pnpm build && pnpm --filter @ferrocast/dashboard e2e` · `pnpm --filter @ferrocast/overlays e2e` |
| **Accessibility** | axe on every screen (designs, both designer views, the theme and widget designers included) in both themes, plus keyboard paths. | `pnpm --filter @ferrocast/dashboard e2e a11y` |
| **Smoke** | Tests tagged `@smoke`: the app boots, the gallery loads, a test alert renders, an overlay plays a design. | `tools/smoke.sh` |
| **Regression** | All of the above. Older suites (flows, errors, community, tips, import, worst case, mobile) stay green with the new code. | `tools/check.sh` |
| **Sanity** | Types, lint and formatting. | `tools/check.sh --fast` |

Notes

- Browser tests run the **built** app (`vite preview`), so build first. Locally a running preview server is reused.
- Tests never touch the real engine, OBS or the network: the dashboard and overlays run the in-browser demo engine, which has the real built-in catalogue.
- Adding a built-in design: see `docs/CONTRIBUTING-designs.md`; the catalogue and overlay render tests pick it up by themselves.

## Studio (streamer tools)

The engine contract is API.md §4 "Studio"; the demo engine implements it in `packages/api/src/demo/features/studio.ts` (a pretend OBS, a Kick sign-in that predates the stream-info permission so the reconnect flow shows).

- **Unit** (`packages/api/test/studio.test.ts`): `checkStreamInfo` mirrors `core::stream_info` (140 characters not bytes, tags in any script, 10 max, language codes, clearing tags); `timecode`; the marker CSV/TXT exports match the engine's (formula injection defused, one line each); Studio live frames parse and malformed ones are dropped; the demo's routes: counters (409 clash with a counter or a built-in, 404 `counter_not_found`, 400), stream info (partial success, 422 `stream_info_failed` with the details in history, 400), Start/End show and the countdown (409, 404 `no_countdown`), clip that (422 until the replay buffer runs, then a clip marker), BRB without a scene (422 `no_brb_scene`), lane dismissals (404), CSV download and a bad format (400).
- **E2E** (`apps/dashboard/e2e/studio.spec.ts`, `studio-mobile.spec.ts`): every Studio tab and Home's Start show button load (`@smoke`); Start show from Home in two clicks, countdown chip, Go live now, End show; a muted mic failing the pre-flight and the one-click unmute; stream info to every platform (2 of 3, Kick says reconnect with a link), only Kick ticked (nobody took it, reason shown), a 502 as a plain message, a bad tag caught before sending; presets save, fill back, delete; OBS scene switching, clip that before and after the replay buffer, BRB and back; Alt+2 hotkey; markers add and CSV/text downloads; the Don't miss lane dismiss and Clear all; counters (+, new, clash), quotes, a module switch; axe on every Studio tab and Bot in both themes (no serious or critical issues); 375 px fit for every Studio tab, Bot and Home, and Start show on a phone.
